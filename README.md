# Мои новости

Своё приложение-лента: собирает посты из публичных Telegram-каналов, оставляет только нужные темы, работает офлайн.

## Как настроить

Всё в файле `config.json`:

- `channels` - каналы: `durov`, `@durov` или `https://t.me/durov`
- `topics` - темы и ключевые слова
  - обычное слово ловит начало слова: `строит` найдёт «строительство», «строители»
  - слово в кавычках `"сро"` ловит только целое слово (не найдёт «сроки»)
- `show_unmatched` - `true`, если нужны вообще все посты из каналов
- `keep_days` - сколько дней хранить новости

После сохранения `config.json` лента пересоберётся сама за 1-2 минуты. Дальше обновляется каждые 30 минут.

## Как устроено

- `scraper.py` - сборщик (запускается GitHub Actions)
- `docs/` - само приложение (GitHub Pages)
- `docs/data/news.json` - готовая лента
